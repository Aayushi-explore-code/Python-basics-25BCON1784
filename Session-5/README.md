# Session 5 - Python Basics & GitHub Workflow

## Objective

The objective of this session was to practice basic Python programming concepts and understand the GitHub workflow for managing and documenting code.

## Programs

The following Python programs were created during this session:

- Factorial
- Fibonacci
- Even/Odd
- Prime Number
- Dictionary
- Sum of Natural Numbers

## Tools Used

- Python
- Git
- GitHub

## GitHub Workflow

The work was managed using Git and GitHub through the following workflow:

1. Create and edit Python programs
2. Track changes using Git
3. Commit changes with meaningful commit messages
4. Organize files into a session-specific folder
5. Push the work to GitHub
